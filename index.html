Infrastructure lab

Kronos-Nexus — a homelab that behaves like production.

A segmented, self-hosted platform: a Proxmox host running the workloads, an OpenWRT router on a Raspberry Pi 4 enforcing VLAN isolation and firewalling, WireGuard for remote access, and a stack of services behind a TLS reverse proxy. Hover a node to see its role.

Internet WAN uplink. Only WireGuard and the HTTPS reverse proxy are exposed inbound.
OpenWRT · RPi 4 Router + firewall. 5 isolated VLANs (office, servers, IoT, home, mgmt), WireGuard VPN, DNS.
WireGuard Encrypted remote access with per-peer, least-privilege firewall rules.
Proxmox Virtualization host running the VMs and containers below.
Pi-hole + Unbound Network-wide DNS filtering with a recursive resolver.
Nginx proxy TLS reverse proxy (Let's Encrypt) terminating all public subdomains.
Nextcloud Self-hosted file storage and sync.
Kubernetes Container orchestration for platform workloads.
Grafana Prometheus + Grafana for metrics, dashboards and monitoring.
